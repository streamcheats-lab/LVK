LVK v13 — исправление исчезающих чатов и меню контактов

1. Распакуй архив. Скопируй содержимое папки LVK-main в корень GitHub-репозитория LVK с заменой.
2. GitHub Desktop → Commit to main → Push origin.
3. Дождись успешного GitHub Pages deployment.
4. Перезапусти установленное приложение или обнови страницу с очисткой кэша.
5. Проверь список личных и групповых чатов и меню ⋮ у первого и последнего контактов.

SQL не требуется. Исправление касается интерфейса и защиты от перерисовки.
Если чаты отсутствуют из-за ошибки прав Supabase/RLS или неактивной подписки PRO, это исправление не меняет серверные права. Смотри текст ошибки в консоли браузера.
