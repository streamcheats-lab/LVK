LVK — групповой онлайн (Supabase Presence)

1. Распакуйте ZIP и скопируйте СОДЕРЖИМОЕ папки LVK-main в корень локального репозитория LVK, с заменой файлов.
2. GitHub Desktop: Commit to main -> Push origin.
3. Дождитесь зелёной галочки GitHub Pages Actions.
4. Supabase Dashboard -> SQL Editor -> New query: откройте LVK_GROUP_ONLINE_SETUP.sql в Блокноте, скопируйте SQL, нажмите Run. Не вставляйте туда JavaScript.
5. На телефоне/ПК обновите сайт. Для проверки откройте одну группу под двумя разными аккаунтами в разных браузерах.

Онлайн показывает только авторизованные аккаунты с активным соединением Supabase Realtime Presence. Число обновляется при изменении присутствия. Если у Supabase Realtime нет доступа, появится «Онлайн: —» или 0, а не выдуманная цифра. Число участников группы и число онлайн — разные величины.
