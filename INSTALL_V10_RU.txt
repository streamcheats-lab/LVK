LVK v10 — контакты и настройки групп

1. В Supabase → SQL Editor запустите ТОЛЬКО LVK_GROUP_ADMIN_SETUP.sql.
2. Скопируйте содержимое LVK-main в корень репозитория GitHub с заменой.
3. GitHub Desktop → Commit to main → Push origin. Дождитесь публикации Pages.
4. Обновите страницу LVK. В контактах действия доступны через ⋮.
5. Откройте группу → ⚙ Настройки группы. Для системной группы используйте аккаунт streamcheats@gmail.com.

Права проверяются серверными функциями Supabase, а не только скрытием кнопки.
Проверьте функции на двух аккаунтах. Если SQL не выполняется из-за особенностей вашей схемы, пришлите текст ошибки.
