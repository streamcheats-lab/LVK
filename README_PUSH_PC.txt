LVK v11 — уведомления на ПК

1. Открой lvk-push-config.js и вставь ПУБЛИЧНЫЙ ключ из Supabase LVK_VAPID_PUBLIC_KEY. НЕ вставляй приватный ключ.
2. Загрузи все файлы сайта на GitHub Pages через GitHub Desktop.
3. На ПК открой LVK по HTTPS, войди в аккаунт, зайди в «Ещё» → «Профиль и настройки» → «Включить уведомления».
4. Разреши уведомления для сайта в Chrome/Edge и в настройках уведомлений Windows.
5. Проверь число подписок SQL: SELECT count(*) FROM public.lvk_push_subscriptions;
6. Для теста отправь сообщение с другого аккаунта, который имеет доступ к личным чатам.
7. Уведомления внутри сайта обновляются примерно каждые 5 секунд; Web Push должен работать при закрытой вкладке, если браузер и ОС позволяют фоновую доставку.
8. Для уведомлений о личных сообщениях серверная функция сейчас требует LVK PRO у получателя.
9. Отметки прочтения внутри сайта хранятся в localStorage конкретного браузера; межустройственная синхронизация пока не реализована.
