LVK v12 — участники и настройки группы

1. Скопируйте всё содержимое LVK-main в корень GitHub-репозитория с заменой.
2. GitHub Desktop: Commit to main → Push origin.
3. Дождитесь зелёной галочки GitHub Pages и обновите сайт.
4. В личной переписке кнопки настроек группы быть не должно.
5. В групповом чате нажмите «Участники»: появится вертикальный прокручиваемый список внутри окна переписки.

SQL для этого обновления не требуется.
